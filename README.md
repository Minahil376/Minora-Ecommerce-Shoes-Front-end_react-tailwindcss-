# 👟 Minora - E-commerce Shoe Website

Minora is a modern e-commerce frontend for a shoe store built using **React.js**, **TypeScript**, and **Tailwind CSS**.  
It focuses on clean UI, component-based architecture, and a responsive shopping experience.

---

## 🚀 Features

-  Product listing with Men's & Women's shoe collections (36 products)
-  Add to Cart functionality with toast notifications
-  Increase / Decrease quantity in cart
-  Coupon code system (SAVE10, MINORA20, WELCOME15)
-  Cart total calculation with tax, shipping & discount
-  Search overlay with filters (category, price, rating, tag, sort)
-  Stock Dashboard with charts (Bar, Doughnut, Line)
-  Inventory management (View, Insert, Update, Delete stock)
-  Newsletter subscription section
-  About page with global stores table
-  Contact form
-  Login & Signup pages
-  Fully responsive design
-  Fast UI using React functional components
-  Type safety using TypeScript

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Charts:** Chart.js + react-chartjs-2
- **Routing:** React Router DOM v7
- **Build Tool:** Vite
- **Package Manager:** npm
